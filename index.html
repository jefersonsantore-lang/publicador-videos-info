Publicador de Vídeos

Informações sobre o aplicativo desktop para Windows.

Termos de Serviço Política de Privacidade

O que o aplicativo faz

O Publicador de Vídeos é um script executado no computador do usuário. Ele monitora arquivos MP4 na pasta de saída configurada e, usando as credenciais autorizadas pelo usuário, tenta enviá-los ao TikTok e ao YouTube. Os vídeos são enviados com as configurações de publicação definidas pelo programa e pelas permissões disponíveis nas contas.

Como funciona

O programa verifica se o arquivo terminou de ser gravado antes de processá-lo. Os vídeos que forem publicados nas plataformas são movidos para uma pasta local de vídeos publicados. Se uma publicação falhar, o arquivo pode permanecer na pasta de saída para uma nova tentativa. O histórico de processamento é armazenado localmente no computador.

O aplicativo não é um site de edição ou armazenamento de vídeos. Esta página serve para apresentar o aplicativo e disponibilizar seus documentos.
