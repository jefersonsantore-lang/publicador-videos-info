Política de Privacidade

Última atualização: 30 de outubro de 2026

1. Quem opera o aplicativo

O Publicador de Vídeos é um script executado localmente pelo usuário em seu computador Windows. Para questões de privacidade, entre em contato pelo endereço informado no final desta página.

2. Informações usadas pelo programa

O programa acessa os arquivos MP4 que encontra nas pastas monitoradas. Para publicar, usa o nome do arquivo como base para o título e envia o vídeo e os dados necessários às APIs do TikTok e do YouTube. A descrição do YouTube pode ser enviada se o usuário a configurar.

O programa também usa credenciais e tokens de autorização das contas. Conforme a configuração, eles podem ficar em arquivos locais do programa, como .env, tiktok_token.json e youtube_token.json. Um banco SQLite local registra o hash do vídeo, o nome do arquivo, o status de publicação em cada plataforma e a data da última atualização.

3. Como as informações são utilizadas

Os vídeos e dados relacionados são usados para realizar as publicações solicitadas nas contas conectadas e para acompanhar o estado do processamento. O programa não deve ser configurado para enviar conteúdo que o usuário não queira publicar.

Quando a publicação nas plataformas é concluída, o arquivo pode ser movido para a pasta local de vídeos publicados. Se houver falha, ele pode permanecer na pasta de saída para uma nova tentativa.

4. Compartilhamento com plataformas

Para realizar as publicações, os dados necessários são transmitidos ao TikTok e ao Google/YouTube por meio de suas APIs. O tratamento feito por esses serviços segue as políticas de privacidade deles:

  • Política de Privacidade do TikTok
  • Política de Privacidade do Google

5. Armazenamento e segurança

O histórico e os arquivos de autorização são armazenados localmente no computador, conforme a configuração do programa. Proteja o acesso ao computador e não compartilhe arquivos que contenham tokens, senhas ou segredos de cliente. O operador deste aplicativo não recebe esses arquivos por meio do script.

6. Retenção e exclusão

Os arquivos de vídeo permanecem no computador até que o usuário os mova ou exclua. O histórico local permanece no banco de dados do programa até ser removido pelo usuário. Os tokens podem ser removidos dos arquivos locais e a autorização pode ser revogada nas configurações de segurança ou aplicativos conectados das respectivas plataformas.

Excluir um arquivo ou token local não remove publicações já enviadas às plataformas. Para removê-las, use os recursos da plataforma correspondente.

7. Página hospedada no GitHub Pages

Esta página informativa é hospedada pelo GitHub Pages. A visita ao site pode envolver o processamento técnico de dados de conexão pelo GitHub, conforme os termos e a política de privacidade do GitHub.
